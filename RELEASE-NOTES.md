# Canvas Cloud 0.2.0

Canvas Cloud joins BlueCloud Office with its violet engraved squircle logo. Local boards, expanded shapes, ink, attached connectors, alignment, minimap, search, frames, editable tables and Kanban text, local comment replies, native backups, SVG/PNG export and print-to-PDF. Updated validation and atomic native export systems. No hosted collaboration or complete competitor parity.

Windows x64 alpha. Public Windows publisher signing is not available. See docs/CODEX_VERIFICATION.md for tested behavior and known limitations. Back up important work using the native file format before updating.
